# Indian Stock Analyzer (NSE/BSE) — Claude Skill

A skill for Claude that analyzes NSE/BSE-listed Indian stocks using web search: current news, upcoming government schemes (PLI, budget allocations), company projects/capex, and BSE/NSE corporate announcements. It scores and ranks stocks, recommends entry/exit timing (intraday) or an ideal holding period (long-term), and picks the best stock(s) for a given budget.

## What's inside
- `SKILL.md` — the skill definition Claude reads
- `references/schema.md` — the output JSON schema with a worked example

## Disclaimer
This skill produces informational analysis from public web sources, not investment advice. It is not built or reviewed by a SEBI-registered advisor. Always verify current prices and consult a qualified advisor before trading or investing.
